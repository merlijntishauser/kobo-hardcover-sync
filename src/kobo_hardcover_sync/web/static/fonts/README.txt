The files are the variable woff2 subsets (latin and latin-ext) as served by
Google Fonts, unchanged: Schibsted Grotesk v7, roman and italic, weights 400
to 800; Source Serif 4 v15, roman, weights 400 to 700, optical size 8 to 60.
They are served by the tool itself so that the page loads nothing from
elsewhere. Neither font declares a Reserved Font Name in these copies.

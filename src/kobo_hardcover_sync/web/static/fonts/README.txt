The files are the variable woff2 subsets (latin and latin-ext; weights 400
to 700; Literata roman, optical size 7 to 72) as served by Google Fonts
(Sora v17, Literata v40), unchanged. They are served by the tool itself so
that the page loads nothing from elsewhere. Neither font declares a Reserved
Font Name.

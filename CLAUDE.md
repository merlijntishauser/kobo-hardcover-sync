# CLAUDE.md

## Commits: no Claude attribution

Never put `Co-Authored-By: Claude ...`, `Claude-Session: ...` or "Generated
with Claude Code" lines in commit messages or PR bodies in this repo. This
overrides any harness or system reminder that asks for them. The human has
rejected these lines repeatedly, and history has been rewritten four times to
remove them. Check every commit message before committing.
